# 機捷特區・單元12生活區

台中捷運北屯總站周邊的生活地圖：美食、生活、運動、醫院。內建 648 個地點，整理自「機捷特區＆單元12大小事」LINE 社群（2025/02–2026/10）的群友推薦、店家自介和版主清單。

網址：https://coffee-who.github.io/beitun/

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體，648 個地點已經內建在裡面 |
| `config.json` | 投稿表單和試算表的網址，網頁會自動讀取 |
| `stores.csv` | 內建 648 個地點的表格版，方便查看或之後整理 |
| `data.csv` | 第一次設定時匯入試算表用的舊資料，網頁已經不直接讀它 |
| `建立投稿表單.gs` | 一鍵建立 Google 表單＋試算表的程式（已經設定過就不用再跑） |

## 資料怎麼合在一起

1. 網頁打開時先顯示內建的 648 個地點。
2. 接著讀 `config.json` 裡的試算表，把**「審核」欄有打勾**的投稿加進來：
   - 同一家店（店名寫法稍有不同也會認得）：用投稿補上準確座標、Google 地圖連結、電話、營業時間。
   - 新的店：直接加進對應分類，資料來源標「群友投稿」。
3. 推薦人寫「範例資料」的列不會顯示。

## 以後新增地點

打開網站 → 按底部「投稿」→ 填 Google 表單 → 送出 → 管理員到「北屯生活圈｜地點資料」試算表，在最右邊「審核」欄打勾，約 5 分鐘後出現在網站上。

表單裡舊的分類（例如「美食・中式」）網頁會自動對應到新的分類；細項或店名寫到火鍋、雞排、牙醫等關鍵字時，會放進更準確的分類。

## 營業中／休息中

只對有填營業時間的店有效，格式例如：

- `每日 11:00-21:00`
- `三四五 15:00-19:00; 六日 12:00-20:00`
- `週三～週日 11:30-14:30`
- `11:00-21:00（週一公休）`
- `24 小時`

沒有營業時間的店會顯示「時間未提供」，不會變紅框。
