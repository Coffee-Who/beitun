# 北屯生活圈

- `index.html`：網頁本體
- `data.csv`：固定資料（直接在 GitHub 編輯）
- `config.json`：投稿表單與表單資料的網址
- `建立投稿表單.gs`：一鍵建立 Google 表單的程式（不用上傳也可以）

## 以後新增地點（最簡單）
打開網站 → 按底部「投稿」→ 填 Google 表單 → 送出。

## 審核
打開「北屯生活圈｜地點資料」試算表，在最右邊「審核」欄勾選 ✓，約 5 分鐘後出現在網站上；沒勾的不會顯示。

## 第一次設定（只做一次）
1. 到 https://script.google.com →「新專案」→ 把 `建立投稿表單.gs` 的內容整份貼上 → 存檔 → 按「執行」→ 允許權限。
2. 在「執行記錄」複製 `formUrl` 和 `sheetCsvUrl` 兩個網址。
3. 在 GitHub 編輯 `config.json`，把兩個網址貼進引號內 → Commit。

## 刪除或修改投稿
打開「北屯生活圈｜地點資料」試算表，直接刪除或修改那一列。
